# Spikes

Throwaway experiments, each answering one question: does this API do what we need, how fast, with what quirks.

- One folder per spike, `spikes/<yyyy-mm-dd>-<question>/`, with a short `README.md` that states the question and the answer.
- Code in `backend/` and `frontend/` never imports from here. When a spike works, its useful part gets rewritten into the app under a spec.
- Recorded audio and images stay out of git.
